# Proiect: Explorarea Camerei Muzicianului

Acest proiect prezintă o **demonstrație interactivă** în care utilizatorul poate explora camera unui muzician și poate interacționa cu diferite obiecte.

## Videoclip Demonstrativ

În videoclipul atașat se poate observa:

* **Pornirea acțiunii** și modul în care utilizatorul este introdus în scenă.
* **Funcționalitatea de *grab***, prin care anumite obiecte pot fi trase, mutate sau manipulate.
* **Interacțiunea cu alte elemente** ale scenei pentru a inspecta în detaliu camera muzicianului.

## Pianul

Pianul care va fi utilizat în proiect este realizat în Blender, însă încă nu este terminat și nu a fost adăugat în repository.

## Scopul

Scopul acestui demo este de a prezenta:

* Interacțiuni intuitive cu obiecte 3D.
* Un mediu explorabil în care utilizatorul poate analiza obiecte și atmosfera camerei.
